# Neovim Config

## Setup

- Neovim version: 0.12.2
- Plugin manager: lazy.nvim
- Language: Lua

## Keymaps

### Python

| Mode | Keymap | Action | Plugin / Module | Notes |
|------|--------------|--------------------------|----------------|-------|
| n | `<leader>pc` | Run current Python file | serpy | Opens terminal split and runs current buffer |

## Plugins

- autopairs (automatic bracket/quote pairing)
- blink.cmp (fast completion engine for LSP, snippets, and buffer suggestions)
- bufferline.nvim (buffer tabs UI)
- nvim-colorizer (highlight color codes directly in files)
- Comment.nvim (smart commenting/uncommenting for code)
- conform.nvim (formatting pipeline and formatter management)
- gitsigns.nvim (Git change indicators, hunk navigation, staging, and inline Git actions)
- lazydev.nvim (Lua development helpers and improved Neovim API completion)
- lazygit.nvim (Git UI integration inside Neovim)
- mason.nvim (LSP, formatter, and tool installer)
- mason-lspconfig.nvim (bridge between Mason and Neovim LSP configuration)
- noice.nvim (enhanced command line, notifications, and message UI)
- nvim-tree (file explorer sidebar)
- nvim-treesitter (advanced syntax parsing and highlighting)
- render-markdown.nvim (enhanced Markdown rendering)
- serpy (custom Python runner plugin for executing Python scripts)
- lualine.nvim (customizable statusline)
- telescope.nvim (fuzzy finder for files, buffers, symbols, commands, and search)
- themery.nvim (colorscheme manager with live preview and persistence)
- todo-comments.nvim (TODO/FIXME/NOTE highlighting and search)
- toggleterm.nvim (terminal management with floating and split terminals)
- trouble.nvim (diagnostics, LSP references, quickfix, and location list viewer)
- undotree (visual undo history browser)
- VimTeX (LaTeX editing, compilation, and PFD viewing integration)
- which-key.nvim (keymap hints popup and shortcut discovery)
